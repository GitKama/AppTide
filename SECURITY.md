# Security

AppTide is an early alpha that can invoke software installers and uninstallers. Report a suspected vulnerability privately through this repository's GitHub security reporting channel when enabled; otherwise contact the repository owner without posting exploit details or sensitive logs publicly.

Do not include credentials, complete inventories, usernames, private paths, or raw installer logs in public reports. Describe the affected version, trust boundary, expected behavior, and a sanitized reproduction.

Known limits: unsigned initial binaries, conservative CLI parsing, no transactional rollback of third-party installers, and no completed external security review. Version 0.1.x is the only development line currently maintained.
