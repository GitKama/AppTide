Coverage, honestly

Windows registry, current-user Store apps, WinGet, and selected portable folders. Other users’ profiles, arbitrary scripts, and every possible portable format are outside this alpha’s scan.

WinGet and optional GitHub release checks use their respective online services. GitHub sources are watch-only; AppTide never guesses which asset to execute.
